📂 Categorías automáticas V8.1

Para que las categorías se guarden en Supabase en todos los celulares, crea esta columna una sola vez en SQL Editor:
alter table productos add column if not exists categoria text default 'Otros';
Aunque no agregues la columna todavía, esta versión acomoda productos por nombre y guarda categorías localmente.

🧹 Limpieza de prueba real

Usa esto solo cuando quieras borrar caché, pedidos locales, ventas locales y menú guardado en este celular.
